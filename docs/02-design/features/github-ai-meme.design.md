# GitHub + GPT 카드 생성 설계

2026-09-30 사용자 승인: 공개 GitHub 조회부터 GPT 칭호·밈 생성까지 연결한다.

## 흐름
POST /api/hero { username } → 공개 프로필, 소유 공개 저장소(최근 갱신 100개), 공개 이벤트(최대 300개/30일) → 규칙 기반 캐릭터 → OpenAI Responses API JSON 출력 → 카드.
공개 이벤트는 커밋 수와 다르다. 활동 없음은 공개 관측 범위의 결과로만 표현한다. 시간대가 없으므로 새벽·주말 습관은 추론하지 않는다.
직업: PR/리뷰 이벤트가 push보다 많으면 기사, 관측 활동일이 5일 이상이면 마법사, 나머지는 도적. 레벨은 1 + floor(sqrt(공개 이벤트 수)), 최대 100. 능력치는 이벤트 종류, 활동일, 관측 저장소 언어 종류로 계산한 게임 수치이며 실제 실력 평가가 아니다.
GPT는 title(최대 24자), quote(최대 70자)만 생성한다. 사실을 만들어내지 않고 입력 데이터 내 특징을 한국어 개발자 유머로 표현한다. 거절·불완전 출력·키 누락·시간 초과는 명시적 오류로 처리한다.

## 운영 및 공유
OPENAI_API_KEY 필수, OPENAI_MODEL 설정 가능(기본 gpt-4o-mini), GITHUB_TOKEN 선택. 키는 서버 전용. 공개 엔드포인트 및 public 이벤트만 사용하고 private 저장소는 제거한다.
동일 username 요청은 프로세스 내 1시간 캐시 및 동시 요청 합치기. 저장 캐시는 최대 200개, 진행 중 생성은 최대 3개. 캐시는 서버 재시작/다른 인스턴스에 공유되지 않는다.
공유 링크에는 생성한 카드 스냅샷을 담아 재방문 시 AI 비용 없이 동일 문구를 복원한다. 스냅샷은 검증하며 사용자 편집 가능 데이터로 취급한다.
존재하지 않는 계정, rate limit, 네트워크 실패, 설정 누락은 인라인 안내. 샘플 도감은 별도로 유지한다.

## 검증
외부 API 응답을 대체한 테스트로 공개 데이터 필터, 페이지네이션, API 오류, JSON 출력 검증, 캐시 및 입력 검증을 확인한다. TypeScript와 production build 실행. 키가 없으면 실제 GPT 호출 검증은 미완료로 보고한다.
